Keyboard keys

Press Tab until a query (or an item without a valid query) has a dashed outline, or type the number of a query. Then:

  • Alt+Up / Alt+Down: previous / next item, from an item or a scope. A collapsed item expands.
  • Down / Up: into the query or scope / out of it. Left / Right: previous / next scope, or out of the scope around them if there is none; on a whole query, its last / first scope.
  • Enter: edit the outlined query or scope. Enter then confirms, Escape or Tab cancels. An empty query or one with an error opens its query box instead.
  • T: on a whole query or an item, go to the title. Escape in the title or query: back to the whole query.
  • 1, 2, 3 …: the query with that number, from anywhere except a text field. For 12, type 1 and 2 quickly.
